# MS/MS 구조 추정 엔진 데모 (Streamlit)

제약사 DMPK·MetID 연구자 미팅용 로컬 데모입니다. Kaggle CASMI 2026 데이터로 개발 중인 우리 엔진(v3)이
MS/MS 스펙트럼에서 구조 후보 Top-25를 고르는 과정을 단계별로 보여 줍니다.

- 앱은 **엔진을 실시간으로 돌리지 않습니다.** 미리 만든 데모 번들(`data/demo_bundle/`)만 읽으므로
  미팅 중 네트워크·GPU·대용량 데이터 없이 동작합니다.
- 데모 분자 15개 = 시험 장비(timsTOF) 천연물 250종(enveda-np-examples)에서 seed 2026으로 뽑은 C1·C2·C3 각 5개.

## 화면

| 메뉴 | 내용 |
|---|---|
| 개요 | 문제(MetID 해석의 수작업 의존), 엔진 한 장 요약, 5단계 흐름 |
| 데모 데이터 선택 | C1/C2/C3 쉬운 설명, 15개 분자 중 선택 (정답 구조 숨김/보기) |
| 입력 데이터 | 메타 정보, 원본 vs 전처리 스펙트럼(거울상), 제거된 피크와 사유 |
| 엔진 처리 과정 | ① 정리 ② 후보 검색(깔때기·출처·유사체 질량 차 변환명) ③ 지문 예측 ④ 조각 매칭 주석 스펙트럼 ⑤ 랭커 SHAP 기여·근거별 단독 순위 |
| 최종 결과 | Top-N 구조 카드·표, 정답 순위, 1위 신뢰도 등급, 정답 vs 1위 비교, CSV |
| 예시 보고서 | 분석 보고서 HTML 미리보기 + 내려받기 |
| MetID 시연 (반응성 대사체) | 아세트아미노펜 → NAPQI → GSH 포합체 경로, 포합체 스펙트럼의 GSH 신호 탐지, 탐지 규칙 점검표 |
| 15개 성능 요약 | C1/C2/C3별 Top-1/Top-5/Top-25/MRR (작은 표본 주의 문구 포함) |

## 1. 설치 (앱 실행 환경)

앱은 번들만 읽으므로 RDKit·PyTorch가 필요 없습니다. 엔진 venv와 분리된 가벼운 환경을 권장합니다.

```bash
python3 -m venv /mnt/14903B8A903B717A/venvs_1T/.venv_casmi_demo
/mnt/14903B8A903B717A/venvs_1T/.venv_casmi_demo/bin/pip install -r demo_app/requirements.txt
```

(이 PC에는 위 경로에 이미 만들어 두었습니다.)

## 2. 데모 번들 생성 (엔진 환경, 약 3~10분)

> **엔진 모듈 의존성**: 번들 생성 스크립트는 `src/casmi/specnet.py`, `pvfp.py`, `generate.py` 등 `feat/specnet` 브랜치의
> 엔진 코드가 필요합니다. 그 브랜치가 main에 합쳐지기 전에는 `feat/specnet` 체크아웃에서 실행하세요.
> 저장소에는 생성된 번들(`demo_app/data/demo_bundle/`, 약 11 MB)이 들어 있어 **앱 실행 자체는 번들만으로** 됩니다.

저장소 루트(casmi26 폴더)에서 엔진 venv로 실행합니다. 라이브러리 캐시, COCONUT/PubChem tier, 검증 run
`runs/big_pc3`(특징 파일), 모델 파일이 필요합니다.

```bash
/mnt/14903B8A903B717A/venvs_1T/.venv_p313/bin/python scripts/build_demo_bundle.py
```

옵션: `--seed 7`(다른 15개), `--n-per 5`(시나리오당 분자 수), `--retrain`(홀드아웃 랭커 다시 학습).

번들이 만드는 것 (`demo_app/data/demo_bundle/`)
- `index.json` 분자 목록, 설정, 신뢰도 보정표, 랭커 특징 중요도
- `mol_<id>.json` 분자별 메타, 원본/전처리 스펙트럼, 단계별 산출물(후보 수·출처, 질량 창, 유사체, 지문 상위 비트,
  조각 설명 피크, SHAP 기여, Top-25), 정답 SMILES와 순위
- `cands_<id>.parquet` 전체 후보와 근거 값, 최종 점수
- `ranker_demo.txt` 데모 15개 구조를 빼고 다시 학습한 랭커

### 누수 방지 (기존 검증과 같은 규칙)
- C1: 질의 구조의 enveda 스펙트럼만 참조에서 제거 (다른 라이브러리 스펙트럼은 유지)
- C2: 질의 구조(및 같은 채점 키 변형)의 모든 스펙트럼 제거, 구조는 후보 풀에 유지
- C3: C2 + 학습 구조 후보 풀에서도 제거 (외부 DB·유도체 생성으로만 찾을 수 있음)
- 참조 마스크는 `runs/big_pc3`와 같은 2,000개 검증 질의 기준
- 모델: FP-net `runs/big_np/fpnet.pt`, SpecNet `runs/big_np/sn2/specnet.pt`(검증 구조 제외 학습),
  FPNet `data/external/leakfree_fp/ours_fpnet_*.pt`(시뮬레이션 구조 제외 학습),
  랭커는 v3 특징 56개로 `runs/big_pc3` 특징에서 데모 15개 구조를 뺀 뒤 재학습.
  (Kaggle 제출용 v3는 전체 데이터로 학습한 가중치를 쓰므로 이 데모와 가중치가 다릅니다.)

## 3. 실행

```bash
/mnt/14903B8A903B717A/venvs_1T/.venv_casmi_demo/bin/streamlit run demo_app/app.py
```

브라우저에서 http://localhost:8501 을 엽니다. 다른 번들을 쓰려면 `CASMI_DEMO_BUNDLE=/경로` 환경변수를 지정합니다.

- 북마크: `http://localhost:8501/?mid=v_209513&page=4` (page = 메뉴 번호 0~7, 0 = 개요, 6 = MetID 시연). 미팅 순서대로 탭을 열어 두면 편합니다.
- 사이드바 맨 위 '화면 테마: 다크 / 라이트' 토글(기본 다크). Streamlit 기본 위젯·표까지 함께 바뀝니다(서버 전체 설정이라 열린 창 모두에 적용).
- 사이드바 '스펙트럼 √강도 표시'(기본 켬): 전구체 피크가 강할 때 작은 조각 피크가 보이게 표시만 바꿉니다.
- 화면 캡처: `docs/screenshots/`, 보고서 예시 파일: `docs/report_example_*.html`

`v_1757`(C2 플라보노이드, 1위), `v_77`(C3, 갈란타민 C17H21NO3 — 학습 구조에서 지운 뒤 PubChem 채널로 찾아 1위), `v_947`(C3, 1위 신뢰도 '높음'인데 틀린 사례 — 한계 설명용).

## 문구 원칙과 한계
- 성능 수치는 번들에서 실제로 계산한 값만 보여 줍니다. 15개는 작은 표본이며, 리더보드 순위는 넣지 않았습니다.
- 신뢰도 등급은 랭커 교차검증(검증 질의 약 6,000건)에서 1위-2위 점수 차별 실제 적중률로 정한 참고값입니다.
  검증 시뮬레이션은 실제 미지 시료보다 쉬울 수 있습니다.
- 구조 계열 표시는 SMARTS 간이 규칙이며 분류 모델이 아닙니다.
- MetID(약물 대사체 질량 이동 등) 적용은 향후 PoC에서 확장할 내용으로만 언급합니다.
  유사체 질량 차에 붙는 변환명(수산화, 글루쿠론산 포합 등)은 질량 차가 일치할 때 붙이는 표시일 뿐입니다.


## 반응성 대사체 경고 (MetID 시연)

코드: `src/casmi/alerts.py`(엔진 쪽 규칙), 번들 생성 시 모든 분자에 적용 → 앱의 '엔진 처리 과정 ⑥', '최종 결과' 주의 플래그, HTML 보고서 6장, 'MetID 시연' 화면.

- 스펙트럼 신호 (전처리 후 스펙트럼, 상대 강도 1% 이상, 허용오차 max(10 ppm, 5 mDa))
  - 양이온: 전구체 − 129.0426 Da (피로글루탐산 중성 손실, 주 신호), 전구체 − 307.0838 Da (GSH 전체, 참고)
  - 음이온: m/z 272.0888 (C10H14N3O6⁻, 주 신호), 보조 254.0782 / 210.0884 / 143.0462 / 128.0353
  - 등급: 강함 = 주 신호 2종 또는 주+보조, 약함 = 주 신호 1종
- 구조 경고: SMARTS 15종 (p-아미노페놀/아닐라이드, 퀴논이민, 퀴논, 카테콜, 아닐린, 퓨란, 티오펜, 니트로방향족, 하이드라진, 마이클 수용체, 에폭사이드, 말단 알킨, 아실 할라이드, 알데하이드 등). 후보 상위 10개와 정답에 적용.
- 탐지 규칙 점검 (학습 라이브러리 실측 스펙트럼, 번들 생성 때 계산):
  GSH S-포합체 31종 — 양이온 스펙트럼 32%(n=282), 음이온 61%(n=146)에서 신호, 구조 단위 17/31종.
  GSH가 아닌 무작위 스펙트럼 19,026개 중 0.6%, 시험 장비 천연물 250종 중 3종에서 우연 탐지.
  데모 천연물 15개는 모두 '신호 없음'. 구조 경고는 천연물에도 흔해(15개 중 7개의 1위 후보) 단독 판단에 쓰지 않음.

MetID 시연 분자 (C1~C3 성능 통계에 넣지 않음)
| ID | 내용 | 입력 | 결과 |
|---|---|---|---|
| m_apap | 아세트아미노펜 (모약물) | **실측** Q-TOF [M+H]+ 4개, [M−H]− 4개 (학습 데이터). 질의 스펙트럼 자체만 참조에서 제외 | GSH 신호 없음, 구조 경고 p-아미노페놀 |
| m_apap_gsh | NAPQI-GSH 포합체 (3-(glutathion-S-yl)acetaminophen) | **이론 예시 (실측 아님)** — 학습 데이터에 이 포합체 스펙트럼이 없음 | GSH 신호 강함 |
| m_hb_gsh | S-(4-하이드록시벤질)글루타티온 (퀴논 메타이드 포획물 형태) | **실측** [M+H]+ 4개, [M−H]− 4개, 이 구조의 스펙트럼은 모두 참조에서 제외(C2) | GSH 신호 강함 (−129, −307 / m/z 272, 254, 210, 143, 128) |

NAPQI 자체는 불안정해 측정 스펙트럼이 없으므로 경로 그림에만 넣었습니다.

이론 예시 스펙트럼 근거 (`scripts/build_demo_bundle.py: theory_rows`): 피크 위치는 화학식에서 계산(C18H24N4O8S, M = 456.1315).
양이온 [M+H]+ 457.139 → −H2O 439.128, −Gly(C2H5NO2) 382.107, −피로글루탐산(C5H7NO3) 328.096, −GSH(C10H17N3O6S) 150.055.
음이온 [M−H]− 455.124 → m/z 272.089(C10H14N3O6⁻), 254.078, 210.088, 143.046, 128.035(GSH 유래), 326.082(−129), 182.028([APAP−S]⁻).
GSH 포합체의 129 Da 중성 손실(Baillie & Davis 1993)과 음이온 m/z 272 전구체 스캔(Dieckhaus et al. 2005)에 근거한 대표 조각만 넣었고,
**강도는 임의 값**입니다. 화면·보고서에 '이론 예시(실측 아님)'를 표시합니다.
MetID 시연 분자는 검증 분리 대상이 아니므로(딥러닝 모델이 학습 중 본 구조일 수 있음) 순위는 성능 근거가 아닙니다.
