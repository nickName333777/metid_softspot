작성: 2026-10-22 · 대상: 다른 컴퓨터(노트북)에서 `nickName333777/casmi26`의 main을 클론해 데모 앱을 띄우는 경우.
이 문서의 순서는 이 PC에서 **빈 폴더에 새로 클론 → 새 가상환경 → 설치 → 실행**으로 직접 확인했습니다(아래 "검증 기록").

## (a) 앱만 실행할 때: 복사할 것 없음

앱은 엔진을 돌리지 않고 번들 파일만 읽습니다. 번들 구성(저장소에 포함):
```
demo_app/data/demo_bundle/
  index.json, calibration.json        분자 목록·설정·신뢰도 보정표
  mol_<ID>.json  (18개)                분자별 스펙트럼·단계별 산출물·구조 그림(SVG)
  cands_<ID>.parquet (18개)            분자별 전체 후보와 점수
```
구조 그림은 번들 안에 SVG로 들어 있어서 노트북에 RDKit이 없어도 됩니다.
번들의 `ranker_demo.txt`(재학습 랭커)는 앱 실행에 필요 없어 저장소에서 뺐습니다.

## (c) 노트북에서 실행 순서

### 0. 준비물
- Git
- Python **3.10 이상** (확인한 버전: 3.13.2). Windows는 python.org 설치 프로그램에서 "Add python.exe to PATH"를 체크하세요.
- 디스크 여유 약 1 GB (가상환경 약 0.5 GB + 저장소)

### 1. 클론
```bash
git clone https://github.com/nickName333777/casmi26.git
cd casmi26
```
비공개 저장소이므로 GitHub 로그인이 필요합니다(`gh auth login` 또는 개인 액세스 토큰).

### 2. 가상환경 만들기
macOS / Linux
```bash
python3 -m venv .venv_demo
source .venv_demo/bin/activate
```
Windows (PowerShell)
```powershell
py -m venv .venv_demo
.\.venv_demo\Scripts\Activate.ps1
```
PowerShell이 스크립트 실행을 막으면 한 번만 다음을 실행합니다: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### 3. 설치 (약 1~2분)
```bash
pip install -r demo_app/requirements.txt
```
(streamlit, plotly, pandas, pyarrow만 설치됩니다. 확인한 버전: streamlit 1.66.0, plotly 7.1.0, pandas 3.0.6, pyarrow 26.0.0)

### 4. 실행 (저장소 루트에서)
```bash
streamlit run demo_app/app.py
```
- 브라우저가 열리지 않으면 **http://localhost:8501** 을 직접 엽니다.
- 미팅 순서대로 탭을 열어 두려면 주소에 붙입니다: `?mid=v_209513&page=4` (page 0 개요 · 1 데이터 선택 · 2 입력 · 3 엔진 처리 · 4 결과 · 5 보고서 · 6 MetID · 7 성능 요약)
- 왼쪽 사이드바 맨 위 **화면 테마: 다크 / 라이트**로 색을 바꿉니다. 빔프로젝터나 밝은 회의실에서는 라이트가 잘 보입니다.
- 끝낼 때는 터미널에서 `Ctrl+C`.

### 5. 미팅 직전 점검
- 인터넷이 없어도 동작합니다(외부 리소스를 쓰지 않음). 단, 처음 `pip install`은 인터넷이 필요합니다.
- 노트북 절전·화면 잠금 해제, 브라우저 확대 100~110% 권장.
- 한 노트북에서 브라우저 창을 여러 개 열면 **테마 설정은 모든 창에 같이 적용**됩니다(Streamlit 서버 설정이라서).

### 자주 나는 오류와 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| `streamlit: command not found` / `'streamlit'은(는) 내부 또는 외부 명령...이 아닙니다` | 가상환경이 활성화되지 않음 | 2번의 `activate`를 다시 실행하거나 `python -m streamlit run demo_app/app.py` |
| "데모 번들이 없습니다" 화면 | 저장소 루트가 아닌 곳에서 실행했거나 클론이 덜 됨 | `casmi26` 폴더에서 실행. `demo_app/data/demo_bundle/index.json`이 있는지 확인 |
| `Port 8501 is already in use` | 이미 다른 Streamlit이 떠 있음 | 그 창을 닫거나 `streamlit run demo_app/app.py --server.port 8502` |
| 첫 실행 때 이메일을 물어봄 | Streamlit 첫 실행 안내 | 그냥 Enter. 저장소의 `demo_app/.streamlit/config.toml`은 저장소 루트에서 실행할 때 읽히지 않으므로, 계속 묻는다면 `streamlit run demo_app/app.py --server.headless true` |
| 글자가 네모(□)로 나옴 | 시스템에 한글 글꼴 없음(드묾) | Windows·macOS는 기본 글꼴로 해결됨. Linux는 `sudo apt install fonts-noto-cjk` |
| `pip`가 pyarrow를 빌드하려다 실패 | 너무 새롭거나 오래된 Python 버전에 바이너리가 없음 | Python 3.11~3.13 사용 |

## (b) 노트북에서 번들을 다시 만들려면 (선택)

번들 생성은 엔진 전체를 돌리므로 무겁습니다. **PC에서 다시 만들어 커밋하고 노트북은 `git pull`만 하는 것**을 권장합니다.
그래도 노트북에서 하려면 다음이 필요합니다.

### 1) 코드: `feat/specnet` 브랜치
번들 생성 스크립트가 쓰는 `src/casmi/specnet.py`, `pvfp.py`, `generate.py` 등은 아직 main에 없습니다.
```bash
git checkout feat/specnet
git checkout main -- demo_app scripts/build_demo_bundle.py src/casmi/alerts.py   # 최신 데모 코드 가져오기
```

### 2) 엔진 환경
Python 3.13, `pip install -r requirements.txt`(저장소 루트) — RDKit **2026.03.3**(대회 채점과 같은 버전), LightGBM, numba, scipy, PyTorch.
GPU는 없어도 되지만(CPU로 수 분 더 걸림), 메모리는 **32 GB 이상**이 안전합니다(PubChem 목록·라이브러리 적재).

### 3) PC에서 복사할 파일 (경로는 저장소 루트 기준, 같은 경로에 두면 됨)

| 구분 | 경로 | 크기 | 비고 |

### 4) 실행
```bash
python scripts/build_demo_bundle.py                 # 약 3분(랭커 캐시 있음) ~ 12분
python scripts/build_demo_bundle.py --seed 7        # 다른 15개 분자
```
결과는 `demo_app/data/demo_bundle/`에 덮어씁니다. 그다음 위 (c)의 4번으로 앱을 띄웁니다.
